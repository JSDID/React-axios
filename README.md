# React Axios Example

Пример простого React-приложения с использованием axios для получения данных с тестового API и современного оформления.

## Функционал
- Получение заголовка и текста поста с https://jsonplaceholder.typicode.com/posts/1
- Асинхронный запрос через axios с обработкой ошибок
- Современный дизайн с использованием локального шрифта Roboto
- Стилизация по методологии БЭМ
- Ограничение текста по строкам с помощью CSS line-clamp

## Быстрый старт

1. Установите зависимости:
   ```bash
   npm install
   ```
2. Запустите проект:
   ```bash
   npm run dev
   ```
3. Откройте [http://localhost:5173](http://localhost:5173) в браузере

## Структура
- **src/App.tsx** — основной компонент, запрос через axios, вывод поста
- **src/App.css** — стили, подключение локального Roboto, line-clamp, БЭМ
- **public/fonts/** — локальные файлы шрифтов Roboto

## Используемые технологии
- React + Vite
- TypeScript
- axios
- CSS (БЭМ, line-clamp, @font-face)

## Локальные шрифты
Шрифт Roboto подключён локально через `public/fonts` и `@font-face` в CSS. Для добавления других начертаний — поместите нужные файлы в папку и пропишите их в стилях.
